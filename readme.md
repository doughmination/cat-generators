# Cat Generator
</div>

Just a simple Python Script so I could make pride varients of the Oneko Cat

## Prequistories
Python 3+

## How to run/generate images:
Setup a virtual enviroment in the root folder, activate it and install the needed stuff:
```sh
python3 -m venv venv

source venv/bin/activate # MacOS and Linux
.\Scripts\Activate.ps1 # Windows Powershell

pip install -r ./requirements.txt
```

Choose what cats you want:
```sh
python3 bake.py # For my filter cats
python3 spirit.py # For the ghost
python3 apride.py # for all pride ones
python3 generate_all # For everything
```
